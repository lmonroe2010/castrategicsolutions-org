The brand's line icons — Lucide at a 1.5px stroke, navy on cream — replacing the emoji the live site uses.

**Source:** Lucide 0.469.0 (`lucide-static`). In this release `home` and `bar-chart-3` are the old names of `house` and `chart-column`; the preview inlines those files.

**Markup:** inline the Lucide SVG with class `ssi-icon` (26px, `navy-600`, stroke 1.5), or load Lucide from a CDN pinned to an exact version. The consumer chooses the icon by name.

**Sizes:** 20–24px in body contexts; 28–32px for section eyebrow icons; 40–56px for large card headers.

**Color:** `navy-600` on cream, `cream-50` on navy, `steel-500` only when the icon is the primary attention-grab.

**Don't:** mix line and filled icons, put background plates or colored circles behind icons, or use emoji in formal materials.
