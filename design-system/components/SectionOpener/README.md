The section-opener pattern — eyebrow, then headline, then lead — the brand's primary rhythm for starting every section.

**Markup:** `div.ssi-opener` containing `div.ssi-opener__eyebrow` (a 1–3 word category label, rendered uppercase with a 28px steel rule before it), `h2.ssi-opener__headline` (a serif statement; wrap one key phrase in `<em>` to set it in italic `steel-500`), and `p.ssi-opener__lead` (one paragraph of sans body). The consumer provides all three texts.

**When to use:** at the top of every major page section ("Who We Are", "Transparent by Design", "Get In Touch").

**Don't:** use exclamation points or marketing-speak in the headline, or emphasize more than one phrase.
